# Surface brief: web directory

Scope: the whole web directory (web/src/app): home, API directory and detail, datasets,
providers, agent setup, about. Visitor mode: Operate (developers find, judge and integrate
APIs); code-led.

Audience and job: developers first (PRODUCT.md); search in Arabic or English, filter by
sector, access and auth, open an entry, copy a runnable example, follow the provider link.
Proof: the catalogue's own evidence and dates; no invented claims.

Memorable moment: the carved access lattice on every row, lit by the access filter.

Unresolved: final product name and logo; public URLs.

## Direction contract

THESIS: A Saudi API directory that reads like a carved Al-Balad rawashin facade: dense,
ordered panels where who-may-use-this is visible at a glance. It refuses the white
card-grid API hub.

OWN-WORLD: coral-stone grey ground, teak-brown ink and hairlines, the painted turquoise of
Jeddah's rawashin as the one accent, faded green for reachable, brick red for restricted,
amber for degraded; dark mode is teak at night with stone-white ink. Readex Pro for Arabic
and Latin UI, JetBrains Mono for code. Square panels, 2px corners, fine teak rules.

STORY: a developer searches, scans dense rows showing access, auth and reachability,
opens an entry, copies an example in curl, Python or JavaScript, then signs up at the
provider, or connects an agent over MCP.

FIRST VIEWPORT: top bar with name, search and EN/عربي switch; a wide search field with live
counts; beneath it a dense two-column sector index; the access lattice legend at the
search field's end.

FORM: candidate 6 of 7, Al-Balad rawashin; seed:745e84e33e159763.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
